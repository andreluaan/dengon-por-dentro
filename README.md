# Dengon por dentro

Apresentação do Dengon, um assistente pessoal que liga a conversa "Você" do WhatsApp ao Claude Code num PC. A página mostra o caminho de um pedido, do celular ao PC e de volta, e as camadas de segurança que ele atravessa.

O site é estático: abra `index.html` ou publique a pasta no GitHub Pages.

O serviço em si fica num repositório privado. Esta pasta é gerada a partir dele com `npm run build:public`, dentro de `por-dentro/`.
